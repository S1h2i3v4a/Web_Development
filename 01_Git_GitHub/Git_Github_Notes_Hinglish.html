Topic 01: What is Git & GitHub?
What is Git?

Git ek Free, Open-Source Version Control System (VCS) hai jo hamare codebase ke changes ko track karta hai aur project history maintain karta hai.

What is GitHub?

GitHub ek online cloud platform/website hai jahan hum apne Git repositories ko host karte hain aur doosre developers ke sath collaborate karte hain.

Git (Local Tool on PC)
➔ Push to Web ➔
GitHub (Cloud Host / Website)
Topic 02: File Status Lifecycle
Git Ke 4 File States:
Untracked (Nayi File)
➔ git add ➔
Staged (Ready for Commit)
⬇ git commit
Unmodified (Saved in Repo)
➔ Edit file ➔
Modified (Changes Made)
Core 3-Step Routine:
$ git add index.html # Step 1: Working directory se Staging area me bhejo $ git commit -m "save msg" # Step 2: Staging se Local Repository me commit karo $ git push origin main # Step 3: Local Repo se GitHub (Remote) par push karo
💡
Key Rule: git add . saare modified & untracked files ko ek sath stage kar deta hai!
Topic 03: Basic Commands (clone & status)
  • git clone <repo_url> ➔ Remote repository ko download karke local machine par copy banata hai.
  • git status ➔ Code ki current state display karta hai (kaunsi file modified hai, staged hai ya untracked hai).
Topic 04 & 05: New Repo & Remote Setup
First Time Repo Setup Steps:
$ git init # Naya empty Git repo initialize karta hai $ git remote add origin <repo_url> # Local repo ko remote GitHub link se jodta hai $ git remote -v # Remote URL verify/check karta hai $ git branch # Saari branches check karta hai $ git branch -M main # Current branch ka naam rename karke "main" karta hai $ git push -u origin main # Pehli baar code remote 'origin' par push karta hai
Topic 06: Branch Commands
Branching Kya Hai? Project ki main line se alag hokar safe features banane ka isolated rasta.
CommandKaam (Action)
git branchActive branches list karta hai (* current branch par hota hai).
git checkout <branch>Dusri branch par switch/navigate karta hai.
git checkout -b <new_branch>Nayi branch banata hai AUR turant uspar switch karta hai.
git branch -d <branch>Purani/merged branch ko delete karta hai.
⭐
Modern Git Tip: Modern Git me git switch <branch> aur git switch -c <new_branch> bhi use hota hai!
Topic 07: Merging Code & Diff
  • git diff <branch> ➔ Do branches, commits ya working tree ke beech changes ko compare karta hai.
  • git merge <branch_name> ➔ Specify ki gayi branch ke code ko current branch ke sath combine/merge karta hai.
$ git checkout main # 1. Main branch pe aao $ git merge feature-login # 2. Feature branch ko main me merge karo
Topic 08: git pull origin main
Pull = Fetch + Merge

Remote repository se latest code download (fetch) karta hai aur turant current local branch ko update (merge) kar deta hai.

$ git pull origin main # Team members ke naye commits apne paas lana
Topic 09: Fixing Mistakes (Undoing in Git)
CaseProblemSolution Command
Case 1 Galti se file stage ho gayi (git add ke baad unstage karna) git reset <filename> ya git restore --staged <file>
Case 2 Aakhri 1 commit galat ho gaya (Commit wapas lena par code rakhna) git reset HEAD~1 (Soft: changes rehte hain, commit hat jata hai)
Case 3 Multiple commits purane kisi specific point par wapas jana git reset <commit_hash>
⚠️
Caution: git reset --hard saare uncommitted changes ko permanently mita deta hai, dhyan se chalayein!
Topic 10: What is Forking?
Fork Concept:

Fork kisi doosre developer ke public GitHub repository ki ek independent Personal Copy hoti hai jo aapke apne account me save ho jaati hai.

Original Upstream Repo
➔ Fork ➔
Your Account Copy (Rough Copy)
⬇ (Changes karke)
Send Pull Request (PR) to Original
  • Yeh original repo ke code aur visibility ko inherit karti hai.
  • Open source me contribute karne ke liye pehle Fork kiya jata hai, phir branch bana kar changes karte hain.
