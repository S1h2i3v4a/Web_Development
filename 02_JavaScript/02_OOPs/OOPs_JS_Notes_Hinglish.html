Topic 02: Factory Functions vs Constructors & new
Factory Functions (Kyun Fail Huye?):

Factory function har baar naya object banata hai, jisse har instance ke liye methods memory mein alag-alag copy hote hain (Heavy Memory Waste!).

Constructor Functions & 'new' Keyword:

Constructor ek blueprint hota hai. Jab hum new lagate hain, toh JS background mein 4 kaam karta hai:

  • 1. Ek brand new empty object {} banta hai.
  • 2. this ko usi naye object se bind karta hai.
  • 3. Naye object ke __proto__ ko Constructor.prototype se jodta hai.
  • 4. Naye object ko automatically return karta hai.

Topic 07: Pillar 2 — Inheritance
Inheritance (Code Reusability):

Inheritance se ek Child class apne Parent class ke features aur methods ko inherit karti hai using extends keyword.

  • super() ➔ Parent class ke constructor ko call karta hai (Child mein this use karne se pehle ise call karna mandatory hai!).
  • super.method() ➔ Parent class ke method ko directly invoke karta hai.

Topic 11: Composition vs Inheritance
Design Principle:

"Favor object composition over class inheritance."

  • Inheritance ("Is-a"): Dog is an Animal. Hierarchical aur rigid hota hai; agar parent mein kuch badla toh saare child toot sakte hain.
  • Composition ("Has-a"): Robot has a Flyer and Cleaner. Flexible hota hai; chote-chote features ko combine karke bada object banate hain.
