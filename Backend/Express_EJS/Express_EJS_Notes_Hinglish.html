Topic 01: Library vs Framework & What is Express?
ConceptDefinition & KaamExample
Library Pre-written code ka aisa collection jise hum kisi specific task ko karne ke liye apni marzi se call karte hain. Control humare haath me hota hai. axios, lodash
Framework Pre-written code ka pura structure/architecture jiske rules ke mutabiq hume code likhna padta hai (Inversion of Control). Express.js

Topic 02: Basic Server Setup & app.use()
const express = require("express"); const app = express(); let port = 3000; // Har aane wali request ko listen karta hai (Middleware) app.use((req, res) => { console.log("Request received!"); }); app.listen(port, () => { console.log(`App is listening on port ${port}`); });
Topic 03: Routing, Params & Query Strings
  • Routing: Network me aane wali traffic/requests ke URL path aur method ke mutabiq sahi response execute karne ka process.
  • Nodemon: Server code modify hone par automatically server restart karne wala development tool.
  • Wildcard Route (*): Agar request kisi bhi path se match na kare toh 404 handler: app.get("*", ...).
// 1. Path Parameters (req.params): /ig/:username/:id app.get("/:username", (req, res) => { let { username } = req.params; // URL variable nikalna }); // 2. Query String (req.query): /search?q=apple app.get("/search", (req, res) => { let { q } = req.query; // Query param nikalna });
Topic 04: EJS (Embedded JavaScript Templates)
What is EJS?

EJS ek simple templating language hai jo plain JavaScript ke sath Dynamic HTML markup generate karne ki suvidha deti hai.

app.set("view engine", "ejs"); // EJS view engine set kiya app.get("/", (req, res) => { res.render("home.ejs"); // views/home.ejs render karega });
⭐
Views Path Rule: Agar server kisi doosre directory se run kiya jaye toh views error na de, isliye path fix karna zaroori hai:
const path = require("path"); app.set("views", path.join(__dirname, "/views"));
Topic 05: Interpolation & EJS Tags

Interpolation: HTML markup text ke andar expressions ya variables ki value inject/embed karna.

EJS TagMeaning & BehaviorExample
<%= %>Outputs value: Variable ya calculation evaluate karke print karta hai (HTML escaped).<%= name %>
<% %>Scriptlet: JS code flow (if-else, loops) chalata hai, screen pe print nahi karta.<% if(age >= 18) { %>
<%- %>Unescaped HTML: Raw HTML render karta hai aur partial sub-templates include karta hai.<%- include(...) %>
<%# %>Comment: Client browser ko send nahi hota, sirf server file me comment rehta hai.<%# This is comment %>

Topic 08: Parsing POST Request Body
Why Body Parser is Needed?

Express by default request body ke data ko parse nahi karta aur req.body undefined hota hai. Isliye middleware lagana zaroori hai:

// 1. HTML Form Data (URL-encoded) ko parse karne ke liye: app.use(express.urlencoded({ extended: true })); // 2. JSON Data (API requests) ko parse karne ke liye: app.use(express.json()); // POST Route handler: app.post("/register", (req, res) => { let { username, password } = req.body; res.send(`Welcome ${username}!`); });
💡
Key Takeaway: extended: true lene se nested objects bhi safely parse ho jaate hain!
