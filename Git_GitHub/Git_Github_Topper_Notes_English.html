Topic 01: What is Git & GitHub?
What is Git?

Git is a Free, Open-Source Distributed Version Control System (VCS) designed to track changes in source code and maintain complete project history over time.

What is GitHub?

GitHub is a cloud-based hosting platform/website where developers store, share, and collaborate on Git repositories online.

Git (Local Tool on PC)
➔ Push to Web ➔
GitHub (Cloud Host / Website)
Topic 02: File Status Lifecycle
The 4 Core File States:
Untracked (New file)
➔ git add ➔
Staged (Ready for commit)
⬇ git commit
Unmodified (Committed in repo)
➔ Edit file ➔
Modified (Unstaged changes)
Standard 3-Step Workflow:
$ git add index.html # Step 1: Move from Working Directory to Staging Area $ git commit -m "save msg" # Step 2: Snapshot staged files into Local Repository $ git push origin main # Step 3: Upload local commits to Remote (GitHub)
💡
Key Rule: git add . stages all modified and newly created untracked files at once!
Topic 03: Basic Commands (clone & status)
  • git clone <repo_url> ➔ Downloads and copies an entire remote repository to your local computer.
  • git status ➔ Displays the state of the working directory and staging area (shows modified, staged, or untracked files).
Topic 04 & 05: New Repo & Remote Setup
First-Time Setup Sequence:
$ git init # Initialize a new local Git repository $ git remote add origin <repo_url> # Connect local repo to remote GitHub repository $ git remote -v # Verify remote connection URLs $ git branch # List local branches $ git branch -M main # Rename current branch to 'main' $ git push -u origin main # Push commits and set upstream tracking
Topic 06: Branch Commands
What is a Branch? An independent timeline to develop features safely without affecting production code.
CommandPurpose & Behavior
git branchLists all branches (* marks the active branch).
git checkout <branch>Switches/navigates to the specified branch.
git checkout -b <new_branch>Creates a new branch AND switches to it immediately.
git branch -d <branch>Safely deletes a merged branch.
⭐
Modern Git Tip: You can also use git switch <branch> and git switch -c <new_branch>!
Topic 07: Merging Code & Diff
  • git diff <branch> ➔ Compares commits, branches, or unstaged changes side-by-side.
  • git merge <branch_name> ➔ Integrates and combines the specified branch into the current checked-out branch.
$ git checkout main # 1. Switch to destination branch $ git merge feature-login # 2. Merge feature branch into main
Topic 08: git pull origin main
Pull = Fetch + Merge

Fetches updates from the remote GitHub repository and instantly merges them into your local active branch.

$ git pull origin main # Pull teammates' latest commits to keep code synced
Topic 09: Fixing Mistakes (Undoing Changes)
ScenarioProblemSolution Command
Case 1 Accidentally staged a file (Unstage after git add) git reset <filename> or git restore --staged <file>
Case 2 Undo last commit but keep code in working directory git reset HEAD~1 (Soft undo: keeps code edits)
Case 3 Roll back multiple commits to a specific checkpoint git reset <commit_hash>
⚠️
Caution: git reset --hard permanently deletes uncommitted changes! Use with care.
Topic 10: What is Forking?
Concept of Fork:

A fork is an independent personal copy of another user's public repository stored under your own GitHub account.

Original Upstream Repo
➔ Fork ➔
Your Account Copy (Rough Copy)
⬇ (Apply fixes & changes)
Open a Pull Request (PR) to Upstream
  • Inherits code and visibility settings from the original repository.
  • Allows you to freely experiment and contribute to Open Source projects without affecting the main project.
