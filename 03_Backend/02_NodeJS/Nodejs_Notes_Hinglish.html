Topic 02: process & process.argv
What is process?

process ek global object hai jo current running Node.js process ki complete information aur control provide karta hai.

process.argv (Command Line Arguments):

Yeh ek array return karta hai jisme command-line se pass kiye gaye arguments store hote hain:

$ node app.js Shivam 22
IndexValueMeaning

Topic 03: module.exports & require()
  • require() ➔ Ek built-in function hai jo alag file/module se exported code ko import karne ke kaam aata hai.
  • module.exports ➔ Ek special object hai jisme hum function, object ya value assign karke doosri files ke liye available banate hain.
math.js: module.exports = sum;
➔ require('./math') ➔
app.js: const sum = require(...)
Directory (Folder) Ko Require Karna:

Agar hum kisi pure folder ko require karte hain: const fruits = require('./fruits'); toh Node.js automatically us folder ke andar maujood index.js file ko execute karta hai!

💡
Analogy: Jaise Java/C++ me main() entry point hota hai, waise hi Node.js me kisi folder ka primary entry point index.js hota hai!
Topic 04: NPM (Node Package Manager)

NPM Node.js ka standard default package manager hai. Iske 2 mukhya roop hain:

1. Library / Registry (Online Packages)
2. CLI Tool (Terminal Commands)
$ npm install <package_name> # e.g. npm i express
Topic 05: Package Files & Folders
File / FolderKaam & Mahatva (Role)
node_modules/ Is folder ke andar aapke project ke saare installed packages aur unki sub-dependencies store hoti hain (heavy size, .gitignore me dalte hain).
package.json Project ki metadata (name, version, scripts, direct dependencies list) store karta hai. Banane ke liye: npm init -y.
package-lock.json Har ek installed dependency ka exact version number lock karke record karta hai taaki sabhi machines par identical setup bane.
Topic 06: Local vs Global Packages
  • Local Install: npm i <package> ➔ Sirf current project ke node_modules me install hota hai.
  • Global Install: npm i -g <package> ➔ Pure computer me globally install hota hai (CLI tools ke liye, e.g. nodemon).
  • npm link: Globally installed package ko local project se connect/link karne ke liye use hota hai.
