ConceptDefinition & RoleExample
Library A collection of pre-written functions that you call at your convenience to perform specific tasks. You retain control of the application flow. axios, lodash
Framework A structured architecture that dictates how your application must be designed. The framework calls your code (Inversion of Control). Express.js
What is Express.js?

A fast, minimalist, and flexible web application framework for Node.js used for server-side programming and building robust web APIs.

Topic 02: Server Setup & app.use()
const express = require("express"); const app = express(); let port = 3000; // Listens to every incoming request regardless of path (Middleware) app.use((req, res) => { console.log("Request received!"); }); app.listen(port, () => { console.log(`App is listening on port ${port}`); });
Topic 03: Routing, Params & Query Strings
  • Routing: The mechanism of mapping client HTTP requests to appropriate server-side handler functions based on URL and HTTP method.
  • Nodemon: A development utility that automatically monitors and restarts the Node server when directory files change.
  • Wildcard Route (*): Matches any unmatched route path (used as default 404 handler: app.get("*", ...)).
// 1. Path Parameters (req.params): /:username/:id app.get("/:username", (req, res) => { let { username } = req.params; // Extract dynamic URL parameter }); // 2. Query Strings (req.query): /search?q=apple app.get("/search", (req, res) => { let { q } = req.query; // Extract query parameter });
Topic 04: EJS (Embedded JavaScript Templates)
What is EJS?

EJS is a simple templating language that allows developers to generate Dynamic HTML markup using plain JavaScript expressions.

app.set("view engine", "ejs"); // Configure EJS template engine app.get("/", (req, res) => { res.render("home.ejs"); // Renders views/home.ejs });
⭐
Views Directory Path Rule: To ensure views render reliably regardless of where the server command is executed from, fix the directory path:
const path = require("path"); app.set("views", path.join(__dirname, "/views"));
Topic 05: Interpolation & EJS Tags

Interpolation: The process of injecting evaluated expressions or variables directly into markup text.

Tag SyntaxRole & FunctionExample
<%= %>Outputs value: Evaluates and inserts value with HTML character escaping.<%= user.name %>
<% %>Scriptlet: Executes JavaScript logic (conditionals, loops) without outputting text.<% if(score >= 50) { %>
<%- %>Unescaped Output: Renders raw unescaped HTML and includes sub-templates.<%- include(...) %>
<%# %>Comment: Internal template comment; excluded from client-side response.<%# Internal notes %>

Topic 08: Parsing POST Request Body
Why Middleware is Required:

Express does not parse HTTP request body payloads by default (resulting in undefined). You must register parsing middleware:

// 1. Parse URL-encoded HTML Form submissions: app.use(express.urlencoded({ extended: true })); // 2. Parse JSON payload requests: app.use(express.json()); // Route handler reading parsed body data: app.post("/register", (req, res) => { let { username, password } = req.body; res.send(`Welcome ${username}!`); });
💡
Key Takeaway: Using extended: true leverages the qs library allowing rich nested objects to be encoded into the URL-encoded format!
