## 📚 Topics & Modules

### 💛 [JavaScript](./JavaScript/)

Comprehensive notes covering basic to advanced modern JavaScript (ES6+):

| Resource | Description | Format |
| :--- | :--- | :--- |
| [**JavaScript Topper Notes**](./JavaScript/JavaScript_Topper_Handwritten_Notes.pdf) | Illustrated notes with diagrams, execution contexts, memory models, exam tips, and detailed code snippets (Topics 01–88). | PDF (16 pages) |
| [**JavaScript Short Notes**](./JavaScript/JavaScript_Short_Notes.pdf) | Concise handwritten pocket notebook for rapid revision and interview prep. | PDF (14 pages) |
| [**Topic Index & Guide**](./JavaScript/README.md) | Complete curriculum breakdown across all 88 covered topics. | Markdown |

#### Highlights Covered:
- **Core Fundamentals:** Variables (`let`/`const`), Primitive & Non-primitive types, Operators, Type Coercion.
- **Data Structures:** Arrays (Linear memory allocation), Objects, Nested Structures, Array of Objects.
- **Functions & Scope:** Declarations, Expressions, Arrow functions, Scopes, Closures, Higher-Order Functions, `this`.
- **Modern ES6+:** Modern array methods (`map`, `filter`, `reduce`), Rest/Spread (`...`), Destructuring.
- **DOM & Events:** Element selection, DOM manipulation, Event Bubbling, Delegation, Event Listeners.
- **Asynchronous JS:** Call Stack, Event Loop, Promises, `async/await`, Fetch API, Axios, HTTP Status & CRUD.
